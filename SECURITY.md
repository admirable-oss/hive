# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Hive, please report it privately through [GitHub Security Advisories](https://github.com/admirable-oss/hive/security/advisories/new).

**Please do not open a public issue for security vulnerabilities.** Private reports give us time to investigate, reproduce, and address the issue before details are disclosed publicly.

We aim to acknowledge reports within a few days and will work with you toward a fix or mitigation as quickly as possible.

When reporting a vulnerability, please include enough information for us to reproduce the issue, including relevant versions, configuration, reproduction steps, and any potential impact.

## Supported versions

Hive is currently pre-release.

For now, **only the latest `main` branch is supported**. Security fixes and mitigations are developed against the latest version of the project.

As Hive approaches a stable release, we will publish a formal supported-versions policy and security disclosure process.

Thank you for helping keep Hive — and the agents running on it — secure.
