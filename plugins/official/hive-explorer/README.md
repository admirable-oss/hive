# Hive Explorer

Official TypeScript plugin for browsing workspace files, previewing text,
searching names and contents, and viewing Git status or diffs. It opens in a
regular Hive popup pane. Build with `bun install && bun run build`; the manifest
runs the checked-in `dist/index.mjs` and `dist/ui.mjs` artifacts.

Install with `hive plugin install` using the official repository and
`--subdir plugins/official/hive-explorer`. See
[the TypeScript SDK guide](../../../docs/plugins/typescript-sdk.md).
