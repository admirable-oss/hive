## Leave them running

Start an agent and walk away.

Hive keeps its environment alive when your terminal closes, your SSH connection drops, or your laptop goes to sleep.

Come back later and pick up where you left off.

## One machine. Many agents.

Run one agent or a hundred.

Each gets its own isolated workspace, terminal, and context — so agents can work independently without stepping on each other.

**Your agents. Your environments. One Hive.**

## See everything working

Know what every agent is doing without opening a dozen terminals.

See which agents are **running**, **blocked**, **waiting**, or **done**.

When something needs your attention, Hive makes it obvious.

## Agents that can operate agents

Hive isn't just where agents run.

Agents can interact with their environment through the Hive interface — creating workspaces, launching tasks, communicating with other agents, and coordinating work.

The infrastructure becomes part of the agent's toolkit.

## Bring your own agent

Use the agents you already trust.

Claude Code. Codex. OpenCode. Cursor. Your own agent. Whatever comes next.

Hive doesn't replace them.

**It gives them somewhere to live.**

## Pick up anywhere

Your work isn't tied to a terminal window.

Disconnect from one machine and reconnect from another.

Your environments stay where you left them.

## Built for the background

Hive is designed for work that takes longer than a terminal session.

Long builds.  

Large migrations.  

Test suites.  

Research.  

Parallel tasks.

Start the work.

**Leave Hive running.**

## One runtime. As many agents as you need.

Persistent environments for coding agents.

No babysitting.  

No starting over.  

No keeping your laptop awake just because an agent is still working.
